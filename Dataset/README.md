# Insurance Dataset

This folder contains the dataset used for the Insurance Risk & Claims Analysis Power BI project.

## Dataset Description

The dataset contains insurance policyholder, vehicle, demographic, and claims-related information.

## Main Fields

- ID
- Birthdate
- Car Color
- Car Make
- Car Model
- Car Use
- Car Year
- Coverage Zone
- Education
- Gender
- Marital Status
- Parent
- Claim Amount
- Claim Frequency
- Household Income
- Kids Driving

## File

`insurance_policies_data.xlsx`

## Usage

The dataset is used for:

- Data cleaning and transformation
- Insurance policy analysis
- Claim analysis
- Customer segmentation
- Vehicle-related analysis
- Power BI dashboard development
