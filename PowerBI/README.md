# Power BI Dashboard

This folder contains the Power BI dashboard developed for the Insurance Risk & Claims Analysis project.

## Dashboard

The dashboard provides an interactive view of:

- Total Policies
- Total Claim Amount
- Claim Frequency
- Average Claim Amount
- Gender-wise Total Policies
- Car Use
- Car Make
- Coverage Zone
- Age Group
- Car Year
- Kids Driving
- Education
- Education & Marital Status

## Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel

## Power BI File

`INSURANCE PROJECT.pbix`

## Dashboard Purpose

The dashboard is designed to analyze insurance policies, claims, customer demographics, and vehicle-related information through interactive visualizations and KPIs.
